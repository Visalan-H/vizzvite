# create-vizzvite

[![npm](https://img.shields.io/npm/v/create-vizzvite)](https://www.npmjs.com/package/create-vizzvite)

Creates a React Vite app but removes all the boilerplate code - giving you a clean starting point! (No boilerplate code)

## 🚀 Quick Start

Create a new React+Vite project:

```bash
npx create-vizzvite my-project
```

Or create in the current directory:

```bash
npx create-vizzvite .
```

## 📁 What You Get

After running the command, you'll have a clean React+Vite project with:

- **Minimal `App.jsx`** - Just a simple component to get you started
- **Reset CSS** - Basic CSS reset in `index.css`
- **Updated title** - Your project name automatically set in `index.html`



## 📋 Project Structure

```
my-project/
├── public/
│   └── vite.svg
├── src/
│   ├── App.jsx       # Minimal starter component
│   ├── App.css       # Empty, ready for your styles
│   ├── index.css     # Basic CSS reset
│   └── main.jsx      # React entry point
├── index.html        # HTML template with your project title
├── package.json
└── vite.config.js
```

## 🔧 Getting Started

After creating your project:

```bash
cd my-project
npm install
npm run dev
```

Your development server will start and you can begin coding immediately!
